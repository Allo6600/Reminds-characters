# リマキャラ（Reminds Characters）

キャラクターに話しかけるだけのシンプルなAIリマインダー。
コンセプトは **「その日のうちに終わらせよう。」**

## 使い方

1. ホームのキャラ「リマ」をタップ → キーボードが出るので、メモ帳みたいにやることを書くだけ
2. AIがメモの内容を把握して、リマインドの時刻を自動で決める
3. 時間になるとホームに吹き出し（ヘッドアップ通知）で教えてくれる
   - 例：「歯医者を予約」→ **あと17時までに電話だよ！📞**
4. アプリ本体には今日のタスクリストを表示。時刻チップをタップすれば後から細かく編集できる
5. **ホーム画面ウィジェット**：キャラ「リマ」がホーム画面に常駐。吹き出しで次のタスクと時間を教えてくれて、時間が来るとセリフが催促に変わる。タップでメモ入力へ
6. **キャラ常駐モード（オーバーレイ）**：アプリ内のスイッチをONにすると、キャラがホーム画面の上を自由に歩き回る。頭上の吹き出しでリマインド、何もない日は「やることある？」。ドラッグで移動、タップでアプリが開く（「他のアプリの上に表示」の許可が必要）

## AIの時刻決定ルール（SmartScheduler）

メモを書いた瞬間にオンデバイスで解析します（外部API・通信不要）。

| メモの内容 | 判定 | リマインド |
|---|---|---|
| 「至急」「今すぐ」 | 緊急 | 15分後 |
| 「15時に〜」「3時半」「15:30」「午後3時」 | 明示時刻 | その10分前（時刻が締切） |
| 「〜を予約」「〜に電話」 | 電話タスク | 営業時間を推定し、閉まる前に通知。締切＝閉店時刻 |
| 「朝」「昼」「夕方」「夜」「寝る前」 | 時間帯 | その時間帯 |
| それ以外 | 通常 | 2時間後（必ず21時までに収める＝今日中） |

営業時間の推定テーブル（例）：

- 病院・歯医者・クリニック：9〜17時
- 美容院・サロン：10〜19時
- 銀行：9〜15時
- 役所・郵便局：9〜17時
- 飲食店・ホテル：11〜21時
- その他の電話・予約：10〜18時

閉店を過ぎていた場合だけ「明日◯時に開いたら電話しよう！」と翌日の開店後に回します。

## 技術構成

- Kotlin + Jetpack Compose（Material 3）
- Room（タスク保存） / AlarmManager（正確なリマインド発火、再起動後も復元）
- `ai/SmartScheduler.kt` … ルールベースの日本語解析エンジン（ユニットテスト付き）
- minSdk 26 / targetSdk 35

```
app/src/main/java/com/reminds/characters/
├── ai/SmartScheduler.kt      # メモ解析・時刻決定（コアロジック）
├── data/                     # Room（Task / Dao / Database）
├── notify/                   # AlarmManager予約・通知表示・再起動復元
├── widget/                   # ホーム画面ウィジェット（キャラ＋吹き出し）
├── overlay/                  # キャラ常駐モード（歩き回るオーバーレイ）
└── ui/                       # ホーム画面・キャラ・メモ入力・時刻編集
```

## ビルド

Android Studio（Ladybug以降）でこのフォルダを開いてそのまま実行。
コマンドラインなら：

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest   # SmartSchedulerのテスト
```
